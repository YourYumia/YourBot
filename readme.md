# YourBot
A personal-use discord bot made by your.yumia for friends and participants of the Fluffy Pup Club private server
![FPC-Banner](./assets/FluffyPupClub-Banner.webp "Fluffy Pup Club")
## Features
Currently, the bot lacks any meaningful features but will operate via slash commands (and perhaps in a few special cases, message-commands). The total feature set is intended to include a few basic user-interaction commands, some API gimmic commands, and possibly some media related commands.
### Command List
### Utility
- **/creatorservers**: Used to access public servers from the creator of your.bot!
- **/sendembed**: Replies with a user defined embed!
- **/ping**: Replies with pong and latency information!
### Warframe
- **/warframe**: Replies with active specified Warframe world-state info!
